# Project handoff (read before coding)
This is **Shabd Coach**, a voice vocabulary agent (Next.js + ElevenLabs). Read these in order:
1. `BUILDLOG.md` — what's done, current state, and the exact next step
2. `BUILDPLAN.md` — phased task checklist (tick boxes as you go)
3. `ARCHITECTURE.md` — decided stack, contracts, edge cases
4. `CONTEXT.md` — product context, research, decisions
After finishing any task: tick it in BUILDPLAN.md, add an entry to BUILDLOG.md, and update CONTEXT.md if a decision changed.
